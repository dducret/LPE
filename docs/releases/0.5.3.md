# LPE 0.5.3

`0.5.3` expands the canonical contact model across the web client, REST API,
JMAP, MAPI, EWS, and ActiveSync.

## Contact compatibility

- Contacts now round-trip photos, postal addresses, categories, birthdays,
  anniversaries, children, spouse, assistant details, web pages, and secondary
  email and phone slots through the canonical `contacts` table.
- Contact photo data is stored with its declared content type; postal, web,
  secondary email, and secondary phone values retain their existing structured
  canonical arrays.
- The schema label is `0.5.3-sql`. This testing-only release directly updates
  the canonical fresh schema; no migration script is supplied.

## Validation

- Protocol contact field behavior is covered by focused storage, JMAP, EWS,
  MAPI, and ActiveSync tests and the web client production build.
