# Tenant dashboard

Operate surface for tenant administrators. It presents tenant-owned domain and account capacity, pending outbound handoffs, and the explicit LPE-CT quarantine boundary. The selected health-first portfolio structure uses a single operational status band above focused domain and account inventories. It must use only authenticated tenant data, make no synthetic risk claims, and remain dense and readable on desktop and mobile.
