# Tenant dashboard

Operate surface for tenant administrators. It presents tenant-owned domain and account capacity, pending outbound handoffs, and the explicit LPE-CT quarantine boundary. Its reference composition is the Tenant Overview: a dark tenant rail, a titled overview header, four operational cards, and focused domain/account inventories. It must use only authenticated tenant data, make no synthetic risk claims, avoid nonfunctional provisioning controls, and remain dense and readable on desktop and mobile.
