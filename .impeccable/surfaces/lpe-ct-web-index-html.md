# LPE-CT management console

Mode: Operate

The LPE-CT console is a perimeter-operations workspace for sorting-center administrators. It carries the shared LPE administration language: a dark navigation rail, a pale quiet workspace, compact high-contrast controls, and dense operational lists. CT remains visually distinct only through its `CT` mark and edge-specific data; it must not imply that LPE core owns relay, filtering, or quarantine state.

The navigation and workspace shell must remain stable across dashboard, filtering, anti-spam, quarantine, reporting, and logs. Existing right-side drawers, full-width management lists, localization, keyboard controls, and working actions remain unchanged. On mobile, the drawer-style navigation and management content remain single-column without horizontal overflow.
